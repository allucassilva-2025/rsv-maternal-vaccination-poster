# RSV maternal vaccination poster

Interactive research poster by Lucas Vieira Silva and Mateus Galvão. Advisor: Leonardo Bastos.

Open index.html to view the poster. The Delta source is poster.dlt; its local component packages are included. The canvas is 2160 x 3840 px.

The observed–expected comparison is conditional on a historical model and does not estimate vaccine effectiveness. The introductory interactive curves include explicitly labelled schematic illustrations.
